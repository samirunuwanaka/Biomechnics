\section{Introduction}
Human gait is the pattern of movement of the limbs during locomotion. Gait analysis involves the systematic study of human motion through observational and quantitative measurement parameters. Understanding kinematics (motion trajectories, velocities, joint angles) and temporal-spatial parameters (gait cycle time, stance/swing ratio, stride length, cadence) is essential in clinical biomechanics, sports performance assessment, and rehabilitation engineering. This practical focuses on analyzing motion capture marker data collected from level walking to quantify gait characteristics.

\section{Methods}
Kinematic data were acquired using an optical motion capture system tracking passive reflective markers placed on lower limb anatomical landmarks (ASIS - ILIACA, PSIS - ILIACP, Greater Trochanter - HIP, Lateral Femoral Condyle - KNEE, Lateral Malleolus - ANKLE, and 2nd Metatarsal Head - TOE). Marker positions were recorded at a sampling rate of $100\,\mathrm{Hz}$ ($0.01\,\mathrm{s}$ interval per frame). The recorded dataset \csvfile{markers.csv} was processed using MATLAB script \csvfile{gait230449N.m}. 

Processing included:
\begin{enumerate}
    \item Reconstructing 2D ($x$-$z$) and 3D ($x$-$y$-$z$) trajectories of pelvic and leg markers.
    \item Tracking vertical ($z$) positions of the ankle and toe markers to identify key gait cycle events: Initial Heel Strike ($\text{HS}_1$), Foot Flat ($\text{FF}$), Heel Off ($\text{HO}$), Toe Off ($\text{TO}$), and Subsequent Heel Strike ($\text{HS}_2$).
    \item Calculating temporal parameters ($T_{\text{cycle}}$, $T_{\text{stance}}$, $T_{\text{swing}}$) and spatial parameters (stride length, cadence, average progression velocity).
    \item Evaluating instantaneous progression velocity from pelvic markers ($x$-coordinate derivative).
    \item Comparing 2D and 3D thigh segment lengths to analyze planar approximation errors.
    \item Computing 2D knee joint angle trajectories using the Law of Cosines on the hip-knee-ankle triangle.
\end{enumerate}

\subsection{MATLAB Implementation Code for Data Processing}
The data extraction and preparation code implementation in MATLAB is given below:

\begin{lstlisting}[language=Matlab, caption={Data initialization and setup in MATLAB (\csvfile{gait230449N.m})}]
% Load the data into array A (marker data)
A = csvread('markers.csv');

% Number of rows (frames) and columns in A
[rA,cA] = size(A);

% Data point (frame) numbers
datapt = A(:,1);

% Right side markers. Each is rA x 3 = [x y z] in mm.
iliaca = A(:, 5: 7);    % anterior superior iliac spine (ASIS)
iliacp = A(:,11:13);    % posterior superior iliac spine (PSIS)
hip    = A(:,17:19);    % greater trochanter (TRO)
knee   = A(:,23:25);    % lateral femoral condyle (LFC)
ankle  = A(:,29:31);    % lateral malleolus (LMA)
toe    = A(:,35:37);    % metatarsal 2nd head (TOE)
\end{lstlisting}

\begin{lstlisting}[language=Matlab, caption={MATLAB code for kinematic calculations, event detection, velocity and knee angle estimation}]
%% Task 4 -- Gait cycle temporal calculations
HS1 = 204;  FF = 230;  HO = 258;  TO = 276;  HS2 = 314;

T_cycle  = (HS2-HS1)/100;    % gait cycle time (s)
T_stance = (TO-HS1)/100;     % stance time (s)
T_swing  = (HS2-TO)/100;     % swing time (s)
P_stance = (T_stance / T_cycle) * 100;
P_swing  = (T_swing / T_cycle) * 100;

%% Task 5 -- Stride length, cadence, average velocity
idx_HS1 = HS1 - datapt(1) + 1;
idx_HS2 = HS2 - datapt(1) + 1;
stride_length = (ankle(idx_HS2,1) - ankle(idx_HS1,1))/1000; % m
cadence       = (2 * 60) / T_cycle;                          % steps/min
v_avg         = stride_length / T_cycle;                      % m/s

%% Task 6 -- Instantaneous velocity
inst_vel_iliacp = ((iliacp(2:rA,1)-iliacp(1:rA-1,1))/0.01)/1000;
inst_vel_iliaca = ((iliaca(2:rA,1)-iliaca(1:rA-1,1))/0.01)/1000;

%% Task 7 -- Thigh segment length comparison
thigh_len_3D = sqrt((hip(:,1)-knee(:,1)).^2 + (hip(:,2)-knee(:,2)).^2 + (hip(:,3)-knee(:,3)).^2);
thigh_len_2D = sqrt((hip(:,1)-knee(:,1)).^2 + (hip(:,3)-knee(:,3)).^2);

%% Task 8 -- 2D Knee Joint Angle
thigh_len     = thigh_len_2D;
leg_len       = sqrt((knee(:,1)-ankle(:,1)).^2 + (knee(:,3)-ankle(:,3)).^2);
hip_ankle_len = sqrt((hip(:,1)-ankle(:,1)).^2 + (hip(:,3)-ankle(:,3)).^2);
knee_angle    = 180 - acosd((thigh_len.^2 + leg_len.^2 - hip_ankle_len.^2) ./ (2 .* thigh_len .* leg_len));
\end{lstlisting}

\section{Discussion of Results}
\subsection{Identification of Heel Strike and Toe Off}
Heel strike occurs when the heel makes initial contact with the ground, corresponding to local minima in ankle height combined with zero or low vertical velocity. Foot flat follows as the forefoot contacts the ground. Heel off is observed when the ankle height begins to rise sharply while toe height remains low. Toe off occurs when the toe marker loses contact with the ground and accelerates upwards into the swing phase.

\subsection{Measurement Sources of Error}
\begin{enumerate}
    \item \textbf{Soft Tissue Artifact (STA):} Skin and muscle movement over underlying bones causes relative motion between optical markers and skeleton landmarks.
    \item \textbf{Anatomical Landmark Placement Error:} Misalignment of markers relative to exact joint rotation centers (e.g., greater trochanter or condyle center).
    \item \textbf{2D Planar Projection Error:} Estimating parameters purely in 2D ($x$-$z$ plane) ignores pelvic rotation and hip abduction/adduction ($y$-axis motion), leading to small deviations in segment length and knee angle calculations.
\end{enumerate}

\section{Conclusion}
In this laboratory session, quantitative gait analysis was conducted using optical marker trajectories processed in MATLAB. Key gait cycle phases, temporal-spatial parameters, instantaneous velocities, and knee angle kinematics were successfully derived. The results demonstrate classic level-walking gait mechanics ($\sim 65\%$ stance and $\sim 35\%$ swing duration) and highlight the importance of 3D kinematic modeling to account for out-of-plane joint motion.
